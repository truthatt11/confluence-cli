# cfl Implementation Plan

> **For agentic workers:** 本計畫由撰寫者在同一個 session 內直接執行（inline）。因為使用者要求直接開始實作，計畫只列出檔案、介面與測試方式，沒有逐步附上完整程式碼。步驟使用 checkbox（`- [ ]`）追蹤。

**Goal:** 以 Go 實作 Confluence Data Center CLI `cfl`，涵蓋讀取、一般寫入、設定指令，並內建 Claude skill。

**Architecture:** `cmd/cfl` 為進入點；`internal/cli` 放 cobra 指令；`internal/confluence` 是 DC REST client；`internal/convert` 是 storage ↔ Markdown 純函式；`skill/` 以 go:embed 打包。

**Tech Stack:** Go 1.24、cobra v1.10.2、goldmark v1.8.6、golang.org/x/term、標準庫（net/http、encoding/xml、encoding/json）。

**Spec:** `docs/superpowers/specs/2026-09-11-cfl-design.md`

## Global Constraints

- Module：`github.com/truthatt11/confluence-cli`，執行檔 `cfl`。
- 只支援 DC/Server，API 路徑預設 `/rest/api`。
- 第三方依賴僅限 cobra、goldmark、x/term。
- 不實作破壞性指令；`api` 僅允許 GET。
- stdout 只放資料；訊息、警告、錯誤寫到 stderr；token 不得出現在任何輸出。
- 檔案 200–400 行為宜，上限 800 行；函式盡量少於 50 行。
- TDD：先寫失敗的測試，再實作；覆蓋率目標 80% 以上。
- 使用者未要求前不 commit。
